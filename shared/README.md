# Общие модули UrbexFinder

`urbex-shared` — устанавливаемый Python-пакет для бота и API. Импорт:

```python
from urbex_shared.catalog import PlaceColumns, published_filter
```

В нём находится единое описание полей общей таблицы `places` и контракт её публичной видимости. У каждого сервиса свой SQLAlchemy registry. Общий пакет не импортирует код сервисов. Сценарии использования, HTTP/Telegram-обработчики, настройки и секреты остаются в сервисах.

Для локальной разработки установите пакет в окружение **каждого** сервиса из корня репозитория:

```bash
python -m pip install -e ./shared
```

Для API дополнительно `python -m pip install -r api/requirements.txt`, для бота — `poetry -C bot install` и `poetry -C bot run pip install -e ../shared`.
Docker-образы устанавливают пакет сами; контекст сборки теперь корень репозитория. Пример: `docker build -f bot/Dockerfile .`. Изменения `shared/` требуют пересборки обоих образов. Изменений `sys.path` для общего пакета нет.

Общие поля добавляет история Alembic бота; пространственные индексы, связи с веб-аккаунтами и переход с `web_places` — история API. Сначала выполняются миграции бота, затем API. Старые миграции используют зафиксированные определения схемы.

Этот пакет не связан с FSD-слоем `frontend/src/shared/`.
